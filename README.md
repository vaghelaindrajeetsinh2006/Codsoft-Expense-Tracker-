# 📖 Overview

Expense Tracker is a personal finance management web application that enables users to track their income and expenses efficiently. The application automatically calculates financial summaries and securely stores all transaction data in the browser using **Local Storage**.

Designed with a clean and responsive interface, it works smoothly on desktop, tablet, and mobile devices.
